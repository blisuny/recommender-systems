# Movie Recommender System

A Python-based movie recommendation project developed using the TMDB 5000 Movies dataset.

## Project Overview

This project analyzes movie data and generates movie recommendations based on movie features and similarities.

The project focuses on data preprocessing, content-based recommendation and similarity analysis.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Project Files

- `original.py` — Original recommendation system implementation
- `path.py` — Alternative recommendation approach
- `tmdb_5000_movies.csv` — Movie dataset

## Dataset

This project uses the TMDB 5000 Movies dataset.

The `tmdb_5000_credits.csv` file is not included because it exceeds GitHub's web upload size limit.

## How to Run

Clone the repository:

```bash
git clone https://github.com/blisuny/recommender-systems.git
cd recommender-systems

Install the required libraries:
pip install pandas numpy scikit-learn matplotlib

Run the project:
python original.py

Alternatively:
python path.py
```
